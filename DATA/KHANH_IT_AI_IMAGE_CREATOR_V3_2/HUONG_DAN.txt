KHÁNH IT - AI IMAGE CREATOR V3
================================

NÂNG CẤP V3
- Giao diện mới tối ưu hơn
- Tạo 1-4 ảnh một lần
- GPT Image 2 / GPT Image 1.5 / GPT Image 1
- GPT Image 2 hỗ trợ trực tiếp nhiều độ phân giải, gồm 4K 3840x2160
- Chỉnh sửa ảnh bằng AI
- Thêm nhiều ảnh tham chiếu
- Tạo poster / banner / logo / wallpaper / quảng cáo sản phẩm
- Lưu PNG / JPG / WEBP
- Lịch sử 100 lần tạo/chỉnh ảnh
- Dùng lại prompt gần nhất
- Tùy chọn lưu API key cục bộ
- API chạy bằng thread nên GUI không bị treo

CÀI ĐẶT
--------
Khuyên dùng Python 3.11 - 3.13.

pip install -r requirements.txt
python main.py

BUILD EXE
---------
pip install pyinstaller

pyinstaller --onefile --noconsole --name "KHANH_IT_AI_IMAGE_V3" main.py

File nằm tại:
dist\KHANH_IT_AI_IMAGE_V3.exe

LƯU Ý API KEY
-------------
Nếu bật "Lưu key trên máy", API key được lưu trong:
app_data\settings.json

Nếu không muốn lưu key, bỏ dấu chọn.
Có thể dùng biến môi trường:
set OPENAI_API_KEY=sk-xxxxxxxx

LƯU Ý MODEL
-----------
- GPT Image 2 là model ưu tiên trong V3.
- Với GPT Image 2, ứng dụng KHÔNG gửi input_fidelity khi chỉnh ảnh.
- Với model cũ, các kích thước không chuẩn sẽ tự quy về:
  1024x1024 / 1536x1024 / 1024x1536.
